Hub for Exploration Opportunities - HEO is a community project aimed at providing a knowledge roadmap and reference materials for young learners aspiring to pursue research in Astronomy, Space Sciences and Technologies, Remote Sensing, Earth Sciences, and Particle Physics.

Access the web here: [thithilia.github.io/Space-Verse/](https://thithilia.github.io/Space-Verse/)
