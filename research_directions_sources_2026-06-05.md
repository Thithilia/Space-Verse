Usage in pages:

- Supported the distinction between vegetation greenness, productivity, and solar-induced fluorescence so the new page would not overstate what any one metric can infer.
- Supported references to MODIS GPP, OCO-2 fluorescence, and ESA FLEX as the most recognizable mission and dataset anchors for beginners.
- Supported the explanation that ecosystem-productivity work usually needs flux towers, field context, and model support rather than image-only interpretation.
- Supported the research-practice examples by combining a NASA mission/program view, a community validation network, and an institute-level biosphere research example.

## Scope notes

- Content was kept introductory and avoided quoting current regional productivity anomalies, agricultural yield claims, or quantitative carbon-uptake estimates that would need tighter spatial and temporal attribution.
- The page emphasizes that fluorescence is closer to photosynthetic activity than simple greenness, but still not a stand-alone proxy for full carbon exchange or ecosystem condition.
- A later run could split this branch further into crop monitoring, drought stress, wildfire recovery, water-use efficiency, or hyperspectral ecosystem remote sensing if the top-level navigation is later reconciled.
